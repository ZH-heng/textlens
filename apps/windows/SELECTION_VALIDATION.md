# Windows 划词手工验收

本文是待执行的实机验收清单。**当前所有项目均未执行，不能视为已通过。**每个应用、缩放比例和显示器组合应分别记录结果。

## 本次实现与边界

- 自动双击只接受至少两个非空白、非控制字符的真实文字选区。UIA 选区矩形命中鼠标，或同一次双击的首击观察与当前 UIA / Edit / RichEdit / Word 范围发生变化，才可通过。对象名称、文件项选择、全文范围和盲目复制均不能证明双击选词。
- 无坐标路径要求首击快照及时完成，并匹配准确的首击代次、窗口、进程和有效期。过快双击、缓慢或不完整的无障碍 provider 仍可能无法验证，此时保持不自动弹出，可用手动捕获快捷键。此限制须逐应用实测，不能宣称覆盖所有软件。
- Windows 不再自动清除宿主文字高亮，避免旧结果关闭时清掉用户刚建立的新选区。工具栏关闭和结果清理只作用于对应选区 ID；macOS 保留现有宿主清理机制，其最终原生调用仍是尽力而为。
- `pnpm verify` 检查当前主机可执行的项目；Windows 上还需运行 `pnpm verify:windows`，再执行下表。macOS 上的独立选区模块 Windows 类型检查不能替代完整 Windows 构建和真实交互验收。

## 准备与记录

1. 在 Windows 10/11 x64 上运行包含本次修改的开发构建。记录 Windows 版本、TextLens 版本/提交、测试日期、测试人、显示器排列及各屏缩放比例。
2. 在设置中启用划词助手，触发方式选择「划词后」并保存。准备记事本或其他原生编辑器、浏览器、Word（若已安装）、PDF 阅读器、资源管理器、第三方文件管理器和 PixPin；记录应用及版本。使用无敏感信息的测试文本，例如 `中文测试 hello world`。
   可在仓库根目录的 Windows PowerShell 中运行 `powershell -NoProfile -STA -File .\apps\windows\scripts\selection-fixture.ps1`，打开原生 Edit/RichEdit、列表、按钮、密码框和空白区域夹具。夹具仅显示自身控件状态；工具栏是否正确出现需人工记录，无法代替其他应用、无坐标 provider 或截图软件测试。
3. 每项至少重复 10 次，记录实际弹出次数与具体操作。对未安装的软件或没有对应设备的项目记录「未执行」及原因，不标记为通过。
4. 需要诊断时，完全退出 TextLens 后在启动它的 PowerShell 中设置 `$env:TEXTLENS_SELECTION_TRACE='1'`；重启应用再复现。日志位于 `%LOCALAPPDATA%\TextLens\selection-diagnostic.log`，包含手势代次、首击观察代次、拒绝阶段、provider、选区证据类型及耗时，不记录选中文字。使用测试文本并在分享日志前检查内容；完成后退出应用并移除该环境变量。若曾创建 `%LOCALAPPDATA%\TextLens\selection-trace.enabled`，也需删除该文件才能关闭日志。
5. 验证至少两种系统双击速度。在具备条件时覆盖 100%、125%、150%、200% 缩放，以及不同缩放的双屏、左侧/上方扩展屏（负坐标）。每次更改后重新记录环境。
